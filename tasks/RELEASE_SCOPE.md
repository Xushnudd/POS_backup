## Joriy topshiriq doirasi

User aniqlashtirishi bo‘yicha tashqi integratsiya va real hardware bandlari CORE-1 implementatsiyasidan chiqarildi va `EXTERNAL-LATER`ga o‘tkazildi. Bu ular tugadi yoki huquqiy talab qo‘llanmaydi degani emas. Core acceptance tashqi compliance/real production rollout acceptance’dan alohida. Real biznes release tegishli tashqi talablar bajarilgachgina yoqiladi.
